# Le Mot Passant

## Le jeu

Le Mot Passant est un jeu de mots pour plusieurs joueurs.

1. Choisis un mot de départ, par exemple « voiture ».
2. Chacun son tour, écrivez un mot ou une expression qui va avec.
3. Vous pouvez utiliser un synonyme (un mot qui veut dire pareil), une expression du rap ou une expression d’Internet.
4. Le groupe choisit si le mot va avec le mot de départ.
5. Le dernier joueur encore en jeu gagne.

Le jeu bloque un mot déjà dit. Le groupe peut refuser un mot qui ressemble trop à un autre, ou qui ne va pas avec le mot de départ.

Au début, choisissez si la deuxième chance est activée. Si elle l’est, chaque joueur peut faire une erreur et réessayer une fois. Après, une nouvelle erreur élimine le joueur. Si elle n’est pas activée, une erreur élimine le joueur.

## Lancer le jeu

1. Décompressez le dossier.
2. Ouvrez `index.html` dans un navigateur.
3. Cliquez sur **Nouvelle partie**.
4. Choisis le mot de départ. Les exemples sous le champ donnent des idées, ils ne choisissent pas le mot à votre place.
5. Choisis les joueurs, le temps par tour et la deuxième chance.
6. Écris le nom de chaque joueur, puis commence la partie.

## Les fichiers

- `index.html` : les textes et les écrans.
- `style.css` : les couleurs, les tailles et la mise en page.
- `script.js` : les tours, le chronomètre, les mots, les décisions et les erreurs.
- `pseudo-code-simple.txt` : les grandes étapes du jeu.
- `pseudo-code-detaille.txt` : le jeu étape par étape.
- `pseudo-code-fonctions.txt` : le rôle des fonctions et des boutons.
- `LIEN-AVEC-LES-COURS.md` : lien avec les cours OpenClassrooms.
- `GUIDE-GITHUB.md` : étapes de base pour Git et GitHub.
- `TESTS-MANUELS.md` : tests à refaire dans le navigateur.

## À savoir

Le jeu repère certains mots qui se ressemblent en comparant leurs lettres. Il peut se tromper. Le groupe choisit toujours si le mot proposé convient. Le jeu ne sait pas comprendre le sens d’un mot ou d’une expression.

Le projet utilise seulement HTML, CSS et JavaScript, sans framework ni bibliothèque externe. Le code reste organisé en petites fonctions avec des noms simples et des commentaires.
